# reader-first-korean

한국어 독자가 글의 요점과 논리, 확신의 정도를 쉽게 파악하도록 돕는 에이전트 스킬입니다. 주어진 정보와 글쓴이의 목소리를 지키면서 실용 글을 초안 작성하고, 기존 글을 윤문하거나 검토합니다.

## 하는 일

- 이메일, 보고서, 설명문, 게시물, 제안서, 발표·영상 대본 초안 작성
- 원문의 뜻과 주장 강도를 보존하는 윤문
- 사실·논리·독해 문제를 우선하는 글 검토
- 번역투, 상투적인 전개, 기계적인 구조와 리듬 점검

허구 원문의 윤문과 검토에는 사용할 수 있지만, 새로운 인물이나 사건을 만드는 허구 창작은 다루지 않습니다. AI 작성 여부를 판별하는 도구도 아닙니다.

## 설계 원칙

- 독자가 복원해야 할 정보와 논리 관계를 필요한 만큼 드러냅니다.
- 주어진 재료가 뒷받침하지 않는 사실, 평가, 인과관계와 화자의 태도를 만들지 않습니다.
- 가능성·권고·의무를 비롯한 주장의 강도를 작업 유형에 맞게 다룹니다.
- 사용자가 지정한 수정 범위와 문체 표본을 일반적인 패턴보다 우선합니다.
- 특정 표현을 금지하지 않고, 실제 기능 없이 반복되거나 글을 흐릴 때만 고칩니다.

세부 계약은 [SKILL.md](SKILL.md), 모델이 반복하기 쉬운 표현과 예외는 [references/patterns.md](references/patterns.md)에 있습니다.

## 설치

[Skills CLI](https://skills.sh/)를 사용한다면 저장소가 공개된 뒤 프로젝트에 설치할 수 있습니다.

```bash
npx skills add sungjunlee/reader-first-korean
```

사용자 전역에 설치하려면 `-g`를 붙입니다.

```bash
npx skills add sungjunlee/reader-first-korean -g
```

또는 저장소를 복제한 뒤 `reader-first-korean` 디렉터리 전체를 사용하는 에이전트의 스킬 디렉터리에 복사하거나 심볼릭 링크로 연결합니다. 스킬 디렉터리 위치는 런타임 설정에 따라 다릅니다.

## 사용

스킬을 명시적으로 호출할 때는 요청과 원문 또는 재료를 함께 제공합니다. 다음은 Codex의 `$` 호출 예시이며, 다른 런타임에서는 해당 런타임의 스킬 호출 문법을 사용합니다.

```text
$reader-first-korean 이 이메일을 뜻과 격식은 유지하면서 자연스럽게 다듬어 주세요.
$reader-first-korean 아래 사실만 사용해 제품 업데이트 공지 초안을 작성해 주세요.
$reader-first-korean 이 글을 고치지 말고 독해를 방해하는 문제만 우선순위대로 검토해 주세요.
```

`agents/openai.yaml`은 OpenAI 호스트에서 표시할 이름과 기본 호출 예시를 담습니다.

자동 스킬 선택을 지원하는 에이전트에서는 한국어 실용 글의 작성·윤문·검토 요청에 자동으로 적용될 수 있습니다.
